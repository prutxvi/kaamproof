# Contributing

Keep changes focused on capture, completeness, source validation and review. Run `npm run check` and `npm test`. Add tests when a change affects evidence acceptance, approval or export status. Disclose reused code and licences.

Never commit real customer records, exported jobs, model weights, API keys or credentials. Use labelled synthetic fixtures. Do not add cloud calls or automatic sending without an explicit product decision.

The application currently has no open-source reuse licence. External reuse contributions should wait for the team to choose one. Native Android and transcription work should begin with measured device compatibility, not claimed support.
